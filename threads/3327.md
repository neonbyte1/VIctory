No device removal and no crash in any arm (also a 25 min warm-up of the candidate, which translated every shader again). The picture matches the base build at the same moments. Frame time is within the noise of these runs (the draw count of the scene differs between arms by up to 2.7x): no regression, no win to claim. These runs are of stage 1 only.

**The full set (375) does not run the title yet:** about 45 s in, before the first scene, the title reads memory that was reserved and never committed (`0xc0000005`, the same place in two runs). Stage 1 alone does not do this, so one of the stage 2/3 merges changes how title memory is mapped. A `git bisect` that runs the title at each step is finding it; its merge will be reverted here and the PR named in this description.
