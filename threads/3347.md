## Description

> [!IMPORTANT]
> GH takes other repositories down, so if anyone wants to stay connected (afterwards), I've created a Discord Account for that: `_neonbyte1`. If anyone adds me, please with a message of your GH name

@Marvisak first, thank you: 300 merged PRs in three days is a lot of reviewing.

The incoming rate is higher than one person can review, though: there are 1,508 open PRs right now, and `main` moves in large batches (the last ones were 2026-11-25 ~22:00 and 2026-11-26 00:27). Between batches, some practical effects show up for contributors and testers:

- **Testers carry their own stacks.** To get the game to render on my setup (RTX 5090, Linux, Wine/vkd3d-proton), my test base is `main` plus about ten unmerged PRs (#2723, #1129, #439, #2118, #2703, #2101, #2312, …). Every result I report is "on main plus these", which is harder for authors to act on.
- **PRs go stale while waiting.** For example, #2465 now conflicts with `main` because the code under it changed; another contributor had to post a port in a comment so it could be tested at all. Each batch of merges triggers another round of rebases across many open PRs.
- **Duplicate work.** With many related fixes open at once, people independently build the same thing (I closed one of my own PRs, #3100, after finding #2312 already fixed it).

**Proposal:** add one or more co-maintainers with merge rights, ideally per area (shaders/emit, GPU/host, HLE/runtime), so well-tested PRs in their area can be merged without waiting for a full batch. Lighter options that would also help, if you'd rather keep merge rights to yourself:

- a `ready-to-merge` label (approved, tested, rebased) that you work through first;
- `CODEOWNERS` per area, so reviews from people who know that code count;
- GitHub's merge queue, so approved PRs are rebased and checked automatically instead of by hand.

I'd suggest picking from people who already review a lot here. I'd also be glad to help myself, for example with Linux/Wine and NVIDIA-specific changes: I test PRs on an RTX 5090 under Wine/vkd3d-proton every day and report the results on the PRs, so I could review and merge in that area if that's useful.
