## Description

The pipeline smoke test now keeps its successful-pipeline check under Wine and runs the existing checksum rejection assertions on native Windows. vkd3d-proton intentionally ignores the DXIL container checksum, so its acceptance of an unsigned or incorrectly signed container does not indicate a pipeline regression. This addresses the failure reported in #1218.

Windows verification used only the repository's synthetic fixture. The focused test ran on WARP, including both native checksum assertions. The shader crate suite passed 120 tests with one ignored. Clippy with all targets and features and the pre-commit asset-policy check passed. Independent Linux verification by @neonbyte1 confirmed that the focused test passes under Wine with vkd3d-proton once #1218 and this PR are applied together. It failed on the same setup with only #1218 applied. The full shader suite passed 120 tests with one ignored. See [the Wine test report](https://github.com/Marvisak/VIctory/pull/1266#issuecomment-7140937315).
