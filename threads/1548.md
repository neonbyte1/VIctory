# Marvisak/VIctory#1548: GPU: preserve full DYNAMIC descriptor range when host view heap is capped at PORTABLE_VIEWS

- PR by @n-romanovich, opened 2026-11-24T19:02:38Z, state **open**

- Archived copy; the original thread is authoritative while it exists.

## Description

## Summary
Fixes Issue #1496, #747.

Preserves the full `DYNAMIC` (`2^18` = 262,144) descriptor range when a host view heap is capped at `PORTABLE_VIEWS` (`1,000,000`, e.g., on NVIDIA) instead of shrinking it to `MIN_DYNAMIC` (`2^16` = 65,536):

- `crates/victory-gpu/src/descriptor/host.rs`: when `count + DYNAMIC > PORTABLE_VIEWS` and `make(count + DYNAMIC)` fails, allocate `PORTABLE_VIEWS` with `count = PORTABLE_VIEWS - DYNAMIC` (737,856) and `dynamic = DYNAMIC` (262,144). `draw.rs::tables()` already remaps any table entry `>= host.count()` into dynamic slots, preventing thousands of world draws from being dropped for lack of dynamic slots.
- Use `checked_add` / `saturating_add` for heap size calculations and update the `MIN_DYNAMIC` doc comment.
- Added unit test `capped_heap_keeps_full_dynamic_range`.
